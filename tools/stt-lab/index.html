STT Lab — Speaking transcription test

Goal: compare browser speech recognition (the same settings as the test engine) with Whisper on the same recordings. The task follows the 2026 structure: one scenario, 7 sentences of increasing length, then 2 interview answers on the same topic. Results: docs/STT-RESULTS.md.

How: ① Open in Chrome and allow the microphone. ② For each item press Record, read the text on screen aloud at your normal pace, then press Stop. (Listen plays a sample pronunciation first if you want.) ③ For the interview items, read the prepared answer below the question, not the question (60 s max). ④ At the end press Download results: one JSON file with your audio and transcripts. About 6–8 minutes. Then run python -I evaluate.py stt_lab_recordings.json small.en.
