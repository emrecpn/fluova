Fluova All tests

Test builder

Draft a section with any chatbot, paste it here, and check it against the same quality gate that every published test passes. Nothing is uploaded: everything runs in your browser.

Step 1

Get a draft

  1. Pick a section below and press Copy prompt.
  2. Paste the prompt into a chatbot and copy its JSON answer.
  3. Paste the answer into the box for that section. Repeat for all four sections.

Complete the Words paragraphs only need a "source" paragraph. The blanks are made by the C-test algorithm, never by hand.

Step 2

Paste the sections

Step 3

Quality gate

To publish: save the file as content/tests/<id>.json, run node tools/build_manifest.js and open a pull request. See CONTRIBUTING.md. You remain responsible for the answer key: the gate checks structure and fidelity, not whether each answer is right.
